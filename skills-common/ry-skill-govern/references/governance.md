# Skill 能力治理视角

本文件用于重新判断已有 Skill 的能力契约、信息关系和运行机制。它提供内部判断坐标，不是每次必须逐项输出的检查清单。

## 从当前意图建立基线

用户输入、旧 Skill、设计记录和运行反馈都只表达部分意图。先回答目标、判断标准、真实边界和目标受众，再决定哪些旧内容仍然成立。

旧稿可能同时包含有效决定、未经验证的假设、过时的平台判断和偶然形成的结构。保留、重构或废弃都由当前决策价值证明。用户拥有关键定位和取舍的裁决权；AI 主动核验事实、发现结构问题并提出候选，不把自己的价值选择写成用户已经确认的决定。

## 建立能力契约

能力契约至少覆盖：

- 服务对象、目标结果和独立存在价值；
- 触发场景、相邻边界和不适用情况；
- 必要输入、预期输出和完成状态；
- 用户授权、权限边界和外部影响；
- 任务路由、判断模型和关键行为方法；
- references、scripts、assets、工具和动态事实入口；
- 目标平台契约与验证条件。

这些是认知维度，不是固定模板。简单 Skill 不需要补齐无决策价值的章节，复杂 Skill 也不能用一条线性流程掩盖并列的对象、来源和任务关系。

设计讨论允许存在候选和未决问题；运行 Skill 只表达已经确认、目标 AI 当前行动需要的内容。下游还会继续设计 AI 时，再判断哪些原则需要向更深层传递。

## 按问题选择权威来源

不同问题使用不同权威，不建立覆盖一切的单一优先级：

| 问题 | 常见权威 |
|---|---|
| 平台支持什么、格式怎样 | 官方规范、官方实现 |
| 当前环境实际怎样运行 | 实例、配置、日志、可重复观察 |
| 源码或资产应改哪份 | 已确认的维护源、生成定义 |
| 用户希望怎样命名、授权和治理 | 已确认的用户决定 |
| 某版本的特殊行为 | 带环境、版本和时间的实测知识 |

来源不一致时暴露差异及其性质。源码与部署副本不同可能是漂移；官方说明与实例不同可能是版本差异；当前状态与用户期望不同不表示某一方自动覆盖另一方。

同一份可维护内容尽量只有一个明确权威来源。其他位置使用链接、索引、生成、部署或有意编译关系；受独立加载和可移植闭包限制的副本需要明确其事实身份，不能与当前源竞争真值。

## 用结构和机制表达能力

结构用于表达职责、作用域、加载、事实所有权和执行边界。只有形成独立职责、加载、维护或执行边界时才拆分文件。

`SKILL.md` 是触发后的能力入口；稳定而必要的细节按需进入 references；重复、确定且容易操作失误的过程才考虑 scripts；作为交付材料而非阅读资料使用的内容进入 assets。资源存在后必须有真实入口说明何时加载或使用。

区分三种成熟度：

- 已有可靠事实和可执行流程；
- 知道能力或端点存在，但契约尚未核验；
- 只有候选设想，尚未形成运行能力。

不要从接口名称、相邻流程或模型常识补全未知 payload、级联影响、回退方式和安全性质。表达问题改善表达，信息错位调整上下文和结构，权限与确定性问题交给真实机制。自由度与任务性质匹配：开放判断保留空间，存在首选模式时提供边界，脆弱而重复的操作使用低自由度机制。

## 保持最小充分

先保证运行必需的目标、用户决定、权限、事实来源、必要输入输出和验证条件可靠可得。对于目标 AI 本可从运行上下文推理的内容，满足以下任一条件才值得显式沉淀：

- 误判会造成显著的安全、权限、数据、成本或返工损失；
- 真实使用或可靠测试表明缺少它会产生稳定重复误判；
- 虽能推出，但取得信息、重建关系或完成推理的成本较高。

根据频率、稳定性和脆弱程度选择介质：高频短规则适合常驻，低频高成本知识按需加载，动态信息保留读取入口，重复确定操作交给机制。删除某项内容不会增加高代价错误、重现已知误判或造成较高推理成本时，不因它正确或未来可能有用就保留。

`description` 负责触发前发现，正文负责触发后行动；不要在正文复制一套已经失去发现价值的触发说明。理由只保留到足以改变判断或阻止误解。

## 从反馈重建而非累积

迭代先判断反馈属于偶发现象、局部产物问题还是可泛化认识，再决定修复表达、调整行为或重构能力。稳定规则、动态状态、阶段方案、历史决策和有时效实测知识具有不同生命周期；正式运行路径保持当前有效，历史退出默认上下文。

比较候选方案时关注：

- 是否忠实解决当前用户意图；
- 目标 AI 是否实际可见、可懂、可用；
- 职责、来源、权限和作用域是否准确；
- 是否保留必要判断空间；
- 新证据出现时能否低成本修正；
- 阅读、同步和误导成本是否低于未来收益。

验证用于暴露隐含背景依赖，不证明产物绝对正确。设计者自检发现显式矛盾；独立复核提供第二视角；受限上下文测试观察目标 AI 是否真正建立预期能力并守住边界。三者按当前变化风险选择，不构成固定阶段。
